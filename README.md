# SmartCab - Cab Booking & Fare Comparison System

SmartCab is a beginner-friendly Python project that simulates a cab booking and fare comparison system using **Object-Oriented Programming (OOP)**.
The system allows users to book rides and compare fares across different cab services such as **Rapido, Uber, and Ola**. Fare calculation depends on the selected cab service, ride type, journey distance, peak-hour charges, and subscription discounts.
The project focuses on applying fundamental OOP concepts to a practical real-world problem.
